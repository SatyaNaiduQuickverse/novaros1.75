1Accelerometer offset & scale

90 seconds. Tumble the airframe so gravity visits every face. This finds the per-axis zero error that tilts which way the sensor believes is down — measured at 0.154 g on this part, worth 8.8°.

2Axis map, against the flight controller

60 seconds. Tumble it again, exactly the same way. The flight controller is a second IMU on the same rigid airframe, so comparing the two recovers how the ESP32 is mounted — which body axis is which, and the signs. No named poses are required: the FC supplies ground truth, so you do not have to hit any particular angle.

  • Nose up — nose toward the sky (pitch stick back)
  • Nose down — nose toward the ground (pitch stick forward)
  • Roll right / left — that side down
  • Level / Inverted — upright, then upside down

3Verify — independently

Nothing above can certify itself: the attitude is derived from the very sensor being calibrated. These two checks use a second, independent sensor and your own hands.
